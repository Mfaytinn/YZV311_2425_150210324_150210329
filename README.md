# Data Analysis Project

## Overview
This repository contains the implementation and analysis for our data science project. For detailed information about the methodology, results, and conclusions, please refer to the accompanying `paper.pdf` file.

## Project Structure
```
.
├── main.ipynb                    # Main notebook with analysis and results
├── requirements.txt              # Python dependencies
├── paper.pdf                    # Detailed project documentation
└── undertanding_and_experiments/ # Additional analysis notebooks
    ├── data_understanding.ipynb
    ├── data_understanding_2.ipynb
    └── data_understanding_3_medium.ipynb
```

## Requirements
The project uses Python with several data science and machine learning libraries. Key dependencies include:
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- XGBoost
- Plotly
- Jupyter Notebook/Lab

## Setup Instructions

1. Clone this repository:
```bash
git clone [repository-url]
cd [repository-name]
```

2. Create and activate a virtual environment (recommended):
```bash
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
```

3. Install the required packages:
```bash
pip install -r requirements.txt
```

## Usage

1. Start by opening the `main.ipynb` notebook:
```bash
jupyter notebook main.ipynb
```

2. Run all cells in the notebook from top to bottom to reproduce the analysis.

## Additional Information

For a complete understanding of the project, methodology, and results:
1. Read the `paper.pdf` for detailed documentation
2. Explore the additional analysis notebooks in the `undertanding_and_experiments` directory
3. Follow the main notebook (`main.ipynb`) for the implementation details
